# M01 — Fourth-down action

Generated 2026-09-08.

> No current game player ratings were used to fit the nflverse baseline.

## model name

M01 — Fourth-down action

## target definition

`action` ∈ {GO_FOR_IT, FIELD_GOAL, PUNT}. FIELD_GOAL if `field_goal_attempt==1`; PUNT if `punt_attempt==1`; GO_FOR_IT if a scrimmage play (`pass_attempt` or `rush_attempt`) occurred. Blocked FGs/punts keep their attempt flag and stay in class.

## eligible population

§6.1 core exclusions + §6.5 REG, then `down == 4` & `qb_kneel==0` & `qb_spike==0` (§6.3). Rows on 4th down with no FG/punt/scrimmage classification were dropped: 0 across all seasons (pre-snap defensive penalties, aborted-then-cleaned edge rows).

## missingness

Predictors are STATE fields. `roof` has no nulls in the population; `temp`/`wind` are structurally null indoors (§17.1) and ~35-45% null for outdoor games — handled by the `env_temp`/`env_wind` construction (outdoor value or neutral) + `temp_missing` flag, not row drops or mean-imputation across roof types.

## important conditional diagnostics

- **Environment (`roof`/`temp`/`wind`) contributes ~nothing**: max Δ log loss between env-on and env-off candidates is 0.0006 on 2024 validation. Kept for completeness but a future prune is safe.
- **4th-and-1-2, 2025**: observed GO rate 0.64 vs predicted 0.56 (Δ +0.07). The model trained on 2023–24 under-predicts short-yardage aggression in 2025 — consistent with the league's rising 4th-down aggressiveness (spec §16: carry 2025 team/coach residuals as tendency priors; do not tune the baseline on 2025).
