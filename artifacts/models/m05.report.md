## model name

M05 — Pass target depth

## target definition

`air_yards` binned: BEHIND_LOS (<0), SHORT (0–9), INTERMEDIATE (10–19), DEEP (≥20). Exact `air_yards` is then drawn from `artifacts/distributions/air_yards_exact.parquet` conditioned on (category × down × field-position band).

## eligible population

§6.1 core + §6.5 REG + §6.2 penalty-free, then `pass_attempt == 1`, `sack == 0`, `qb_spike == 0`, `air_yards` non-null (~7% of pass plays have null air_yards — throwaways, batted balls; excluded per spec §11 M05).
