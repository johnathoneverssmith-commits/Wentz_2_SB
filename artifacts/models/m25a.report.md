## model name

M25a — Pre-snap (dead-ball) penalty hazard

## target definition

P(DEADBALL_PEN): an accepted dead-ball foul on this snap (`penalty == 1` and `penalty_type` ∈ {False Start, Delay of Game, Encroachment, Neutral Zone, Illegal Shift/Motion/Formation, Too Many Men, Illegal Sub}). Enforcement is fixed (5 yд, replay down) so only the hazard is modelled.

## eligible population

RAW stream (keeps `no_play` — dead-ball fouls negate the play), REG, not deleted/aborted, real down + yardline, not kneel/spike. One row per pre-snap scrimmage opportunity.
